# APP Mantención Genérica — QAS

Ambiente de pruebas: https://isaacjorquera5823-dev.github.io/app-mantencion-generica-qas/

- **Qué rama está publicada:** la que dice el archivo `RAMA`.
- **Cambiar de rama:** editar `RAMA` y guardar. Se vuelve a publicar solo en ~2 minutos.
- **Traer los últimos cambios de la misma rama:** pestaña *Actions* → *Publicar QAS* → *Run workflow*.

En QAS la app corre en **modo prueba** (badge naranjo "Modo prueba"): los informes se numeran `PRUEBA-XXXX` y lo que se guarde queda separado de PRD.

El código de la app vive en https://github.com/isaacjorquera5823-dev/app-mantencion-generica — este repo solo contiene la configuración para publicar QAS.
